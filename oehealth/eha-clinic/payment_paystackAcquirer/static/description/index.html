About

The problem and solution

The Problem:

Odoo ships with alot of payment acquirers by default but local west african businesses seems not to be considered... What if we can receive payment online via Paystack?

The Solution:

This module makes it possible for local west african businesses to receive payment from any part of the world through paystack.

Features

What this module does

Receive payment of website sales via card

Usage

Installation and Configuration

Live Video
  1. Get your public and secret keys from paystack
  2. Go to Website -> Configuration -> eCommerce -> Payment Acquirers or Accounting/Invoicing -> Configuration -> Payments -> Payment Acquirers; scroll or search for paystack and click activate.
  3. In the Credentials tab, enter the Public and Secret key from Paystack obtained in 2
  4. In the Configuration tab, set the display name and journal.
  5. Enable and Save to make the acquirer available for use in the eCommerce
