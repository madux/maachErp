Point of Sale LOT Expiry Warning Odoo Apps

Point of Sales Product Lot expiry warning odoo app shows warning to point of sale users while selling product with expired lot or serial number. It also warns users if lot/serial number does not exist for selected product, Users also have the option to restrict creating new lot/serial number for product if expired or not exist.

Features

POS LOT Expiry Validation

Warn pos user on adding product if lot/serial number expired.

POS LOT Exist Validation

Warn pos user on adding product if lot/serial number not exist.

Restrict User from Creating New Lot if Expired.

Restrict user from creating new lot for product if expired.

Restrict User from Creating New Lot if Not Exist.

Restrict user from creating new lot for product if not exist.

POS Lot Expiry Configuration

Under Point of Sale > Configuration > Point of Sale menu user need to enable "Allow Lot Expiry Warning".

Product Lot Expiration Configuration

Under Inventory tab of product user need to enable "Expiration Date" in order to add expiry date for lot/serial number.

Lot Alert Date

Under Inventory > Products > Lots/Serial Number menu user can add "Alert Date" for lots/serial number.

On clicking product on pos screen user will asked to enter lot/serial number for product.

Lot Expired Warning

If entered lot/serial number is expired then warning will show as below image, User can also see product is added with same lot.

Lot Not Exist Warning

If entered lot/serial number not exist for product then warning will shown as below image, User can also see product is added with same lot.

Restrict User from Creating New Lot

User can enable "Restrict User from Creating New Lot" option to restrict user from creating new lot for product if expired or not exist.
